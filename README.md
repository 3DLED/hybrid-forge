# Hybrid Forge

The public pages for Hybrid Forge, a training app for strength and running, served by GitHub Pages:

- https://3dled.github.io/hybrid-forge/ (support)
- https://3dled.github.io/hybrid-forge/privacy.html (privacy policy, linked from the App Store and Google Play)

Plain HTML with nothing fetched from anywhere else. The app's own code lives in a separate,
private repository, which keeps its own copy of `privacy.html` in `docs/`; change the two together.
